# DESIGN.md — Фабрика Хайпа 42

Концертная афиша Пятёрки: ночь, золото софитов, розовый неон. Палитра свята.

## Токены

- `--gold: #f5c518` — главный интерактив, заголовки, зона ритма
- `--bg: #0d0716` — ночь фона
- `--panel: #1c102e` — карточки, шапка
- `--line: #3d2457` — рамки неактива
- `--pink: #ff4fd8` — уровни, курсор, рейд-акценты
- Текст `#f2eafc`, приглушённый `#b9a3d6`

## Типографика

Системный стек (`system-ui, Segoe UI`). Мачта — 900 вес, `clamp(26px,7.5vw,44px)`,
золото со свечением. Цифры ресурсов — `tabular-nums`.

## Композиция

Столбец 640px по центру. Липкая мачта-афиша → сегмент-табы (4 сцены) →
карточки. Ритмполоса — портал 76px с золотым ореолом; бегунок и зона —
инструмент, не декор. Победа — модалка `Dialog` с золотым кольцом.

## Движение

Один вход (подъём мачты/табов, CSS, `backwards`). Попадание — `pop` 180мс.
Хейтер трясётся. Игровой цикл — rAF по сырому времени, стейт только на
событиях. Всё глушится под `prefers-reduced-motion`.

## Компоненты shadcn

`Button` (CTA раздачи), `Card` (площадки/магазины), `Tabs` (сцены),
`Badge` (уровни/комбо), `Dialog` (триумф), иконки — `lucide-react`
с `data-icon`. Игровые эмодзи (ноты 🍾, хейтеры 😡) — контент, не хром.
