> Нарушение буквы гейта = нарушение его духа. Рационализации
> («мелочь», «я уже читал», «сначала код, чеклист потом»,
> «скилл-гейт — оверхед», «этот промпт — исключение») — не аргументы.

1. Прочитай `.impeccable/SKILLS.md` целиком (Tier 0 — все ряды,
   Tier 1 — выбери по триггерам, Ритуал — все пункты). В каждом промпте.
2. Загрузи скилл `sasha42` (обёртка закона: гейты, триггеры, красные флаги).
3. Дальше — строго по SKILLS.md, не по памяти.

## Всегда работаем по скиллу impeccable

Любая работа с интерфейсом этого проекта (дизайн, редизайн, критика, аудит,
полировка, анимации, цвета, тексты, состояния, адаптив) идёт строго по скиллу
**impeccable** (`/root/.hermes/skills/impeccable/`, версия 4.1.3).

- Перед работой загрузи `SKILL.md` скилла и действуй по нему, а не по памяти.
- Команда уже выбрана пользователем — грузи её референс из `reference/` и следуй ему.
- Перед правками UI грузи `reference/craft-floor.md` (порог качества, запреты).
- Без аргумента — читай `reference/routing.md` и показывай меню, ничего не запускай сам.

## Авторитеты проекта (не выдумывать заново)

- `PRODUCT.md` — правда о продукте (аудитория, фишки, нерушимое, принципы).
- `DESIGN.md` — зафиксированный визуальный мир, менять только командой редизайна.
- `.impeccable/config.json` — `buildPath: comp`: новые экраны начинаются с картинки.
