# DESIGN.md — Нейросеть в подвале 42

Мир: ночь Саши (#070b18 фон, панели #0d1428), кобальт #0060AA (действие,
датасеты, доход), алый #E31E25 (галлюцинации, заголовок), серый #808080
(неактив). Segoe UI, пилюли 999px, tabular-nums в HUD.

Композиция: один столбец 680px. HUD-пилюли липкие сверху (датасеты, монеты,
доход/с, версия, галлюцинации). Первый экран — стойка серверов: 4 слота
железа со светодиодами (зелёные гул, алые каждые 4-е) + кнопка разметки.
Табы Подвал/Железо/Модель (shadcn, вертикаль чинена своим CSS).

Движение: один вход rise 0.5s без backwards-филла (контент виден всегда);
мигание светодиодов; победа — один GSAP back.out поп поверх. Всё глушится
под prefers-reduced-motion.

Состояния: disabled-кнопки серые, слоты пустые с подсказкой, риск-пилюля
алеет при галлюцинациях >40%, победа — диалог с продолжением игры.
