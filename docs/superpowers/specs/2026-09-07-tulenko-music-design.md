# Побег тюленьки. Звук на Струделе: замысел

Дата: 2026-09-07. Настрой: тюремный шансон-чиптюн.
Движок: Струдель вшит в игру, играет живьём узорами текстом.

## Устройство

- Движок лежит в деле: `tulenko.bratuxa.zomb.top/lib/strudel-bundle.js`
  (сборка esbuild из `@strudel/web`, ужатая; только свои звуки-синты,
  сеть не нужна).
- Узоры текстом: `tulenko.bratuxa.zomb.top/src/songs.ts` — строки узоров.
- Новый раздел `tulenko.bratuxa.zomb.top/src/music.ts`: заводит движок
  после первого ввода игрока, даёт `music('day'|'night'|'alarm')`
  и `sfx('step'|'pickup'|'door'|'hit'|'cell'|'win'|'lose')`.
- Кнопки звука нет по приказу: музыка просто есть.
- `index.html` грузит `lib/strudel-bundle.js` обычным скриптом до `game.js`.
- Сборка game.js склейкой как раньше; движок отдельным файлом.

## Состав

Темы петлёй:
- день — бодрый шансон-чиптюн, гармошка-пила, бас, стук;
- ночь — тихий стелс-перебор, редкие высокие;
- тревога — быстрый стук и низкая пила при розыске выше нуля.

Короткие: шаг, подбор, дверь (на затемнении), удар, карцер,
победа, поражение.

Переключение само: время суток из часов, тревога из розыска.
Правка музыки — переписать строку узора, в движок не лезть.

## Тишина

Не завёлся движок или окно без звука — молча назад к готовым
гудкам `blip` из `src/audio.ts`. Игра не встаёт, ошибок наружу нет.

## Проверки

- Пробы без звука: движок-заглушка, зовём музыку и звуки — игра
  отвечает, пробы зелёные.
- Смотр: гоняю темы в безголовом окне, проверяю игру без ошибок,
  пишу выход в звуковые файлы и отдаю человеку послушать.
  Судья звука — человек.

## Что не входит

Сеть за звуками, голоса, второй движок, кнопка звука.

## Исходники узоров

Узоры живут в `src/songs.ts` и в `scripts/strudel/*.strudel`
копиями для прослушки. Проба связки уже чистая: завод, игра,
остановка без ошибок и без сети.
