# sasi42io — змейка в стиле батальона 42 — дизайн-спек

Дата: 2026-09-08. Статус: на ревью у Sansy⁴². Кода нет — только этот спек.
Путь: архитектурный (новый сайт с нуля). Подход А: один файл, Canvas2D.

## 1. Цель
Одиночная игра по типу slither.io на `https://sasi42io.bratuxa.zomb.top/`:
змейка игрока против 8–11 ботов, рост за еду, буст, таблица лидеров.
Стиль батальона 42. Ссылка выдаётся только после проверки 200.

## 2. Геймплей (одобрено с правкой: 3 типа еды)
- Арена с едой; управление мышью/пальцем (змейка идёт за курсором), буст на
  пробеле/тапе — тратит длину.
- Еда трёх типов (веса спавна и рост — настраиваемые, стартовые значения):
  1. Банан 🍌 — чаще всего (вес 70), рост +1.
  2. Связка из 3 бананов 🍌🍌🍌 — реже (вес 25), рост +3.
  3. Баночка энергетика Tornado 🥫 — очень редко (вес 5), рост +8.
- Врезался головой в чужое тело — лопнул и рассыпался едой (тип 1);
  бот врезался в тебя — его длина становится едой вокруг.
- Боты: 8–11 штук, имена из батальона, три уровня наглости
  (трусливый / обычный / охотник). Таблица топ-10, рекорд в localStorage,
  рестарт одной кнопкой.
- Структура кода с изоляцией чистой логики (`window.__hook`) — задел под
  будущий мультиплеер, без лишней архитектуры сейчас.

## 3. Оформление 42 (одобрено)
Тёмная арена с сеткой и виньеткой; змейка игрока янтарная, боты —
циан/красные оттенки; свечение головы; HUD в стиле батальона;
экран смерти с «Мы уже победили 🏆» и кнопкой рестарта.
Эмодзи только для еды и декора (стиль 42).

## 4. Сдача (одобрено)
- Один `sasi42io.bratuxa.zomb.top/index.html` (CSS+JS инлайн) + маяк трекера
  (`SITE='sasi42io'`, POST на хаб каждые 30с).
- Карточка в хабе; регистрация в sasha-трекере (SITES, Stats.tsx, сборка).
- TLS через привратник (Caddy) по рецепту battalion-site-ops; проверка 200.
- Тесты: `node --check` инлайн-скрипта, headless-тест логики через `__hook`.

## 5. Самопроверка спека
- Плейсхолдеров нет; числа еды — стартовые, явно настраиваемые.
- Противоречий нет: один файл, без сервера; мультиплеер — вне скоупа.
- Скоуп — один план: игра + сдача (трекер, хаб, sasha, TLS).
