# ШТУРМ-43 — 3D-апгрейд: мобы, карты, текстуры, анимации, оружие, эффекты

Дата: 2026-09-06. Статус: дизайн согласован с Miqqil посекционно (чат).
Скиллы: threejs-materials/textures/animation/postprocessing, subagent-driven-development,
test-driven-development, verification-before-completion.
(`develop-web-game` как отдельный скилл отсутствует; superpowers = семейство скиллов, применяется.)

## Решения (зафиксировано)
- Стиль врагов: гуманоиды как сейчас, детализированные; шуба-игрок выделяется мехом (вариант B).
- Бюджет: ~3-5к треугольников на моба, детали геометрией (средняя детализация).
- Анимации: авторские клипы (AnimationClip в коде) + блендинг по скорости, как у шубы (вариант B).
- Риг: иерархия THREE.Bone в коде + SkinnedMesh (вариант A).

## Секция 1 — враги (`src/three/mobs.ts`, перепил)
- Единый скелет-билдер: таз → позвоночник → голова; плечи → локти → кисти;
  бёдра → колени → стопы. Чайка-босс: крылья (плечо → локоть → кисть-крыло с перьями).
- Тела — SkinnedMesh из боксов/цилиндров со скин-весами (сгиб в суставе).
  Детали — обычные меши на костях: броня танка, подсумки, фонарь-прицел стрелка, клюв/перья чайки.
- Клипы на вид: idle (дыхание), walk (походка), attack (замах/выстрел), death (падение, LoopOnce).
  Блендинг по скорости как у шубы (shuba.ts), attack аддитивно поверх.
- Лимит ≤5к треугольников на моба; shared-материалы (пул); castShadow, без личных источников света
  (кроме фонаря стрелка — emissive + SpotLight с существующим setMobLightDetail).

## Секция 2 — текстуры (новый `src/three/textures.ts`)
- Canvas-генераторы 256/512: мех (шум + ворс), камуфляж (пятна), ржавчина/потёртости,
  ткань-саржа, неон-вывески (текст + свечение).
- Набор на материал: map (sRGB) + roughnessMap (второй проход того же canvas) + emissiveMap
  где надо (неон, линза фонаря, глаза).
- Кэш-пул: одна текстура на вид поверхности на всех (без дублей); repeat/wrap по месту.
- Применение: мобы (мех/ткань/броня по видам), карты (земля/стены вместо сплошного цвета).

## Секция 3 — карты (расширение `src/three/mapsVisual.ts`)
- Статика merged в 1-2 меша (как сейчас). Наборы:
  - Двор: забор-доски, будка, покрышки-баррикады, ящики, лужи (глянец + env).
  - Остров: пальмы, камни, вода по краю (скролл opacity), песок с рябью.
  - Неон: билборды-вывески, трубы, голограммы (аддитив), мокрый асфальт.
- Атмосфера: остров — лёгкий тёплый FogExp2; неон — bloom вывесок + плотный синий туман;
  двор — без тумана, резкие тени.

## Секция 4 — оружие (перепил `src/three/guns.ts`, 1-3к треугольников на ствол)
- Пистолет/автомат/дробовик: ствол с мушкой, затвор, магазин, скоба, приклад/рукоять, прицел;
  автомат — изогнутый рожок, дробовик — помпа + толстый ствол.
- Материалы: воронёный металл (metal 0.9, rough 0.35 + потёртости), дерево-орех, пластик.
  Дуло строго -Z. Отдача пружиной + вспышка-спрайт + дымок; гильзы — пул с гравитацией.

## Секция 5 — эффекты (расширение `src/three/effects.ts`, всё пулы)
- Взрыв: аддитивный пуф + PointLight-вспышка без теней + осколки; кривая затухания.
- Кровь: Points-брызги с гравитацией + декали-пятна на земле (пул, затухают).
- Карточные: FogExp2 (остров/неон), неон-bloom, искры рикошета от танка, дымный след ракеты ZOV.

## Секция 6 — перфоманс и приёмка
- Бюджет: shared-материалы/текстуры, merged-статика, пулы, тени только sun;
  миксер-апдейт только видимым/ближним мобам. Цель: FPS не ниже текущего, draw calls ≤120.
- **Визуальная приёмка (требование Miqqil):** каждая модель до интеграции — вертушка:
  скриншоты спереди/сбоку/сзади/в движении; геймплей — скрины действий
  (idle/walk/attack/death/взрыв) на каждой карте; смотрю, дорабатываю, повторяю.
- Техпроверка: bun test зелёные + сборка + браузер (меню/бой, консоль 0 ошибок).
- Коммит `shturm: 3D-апгрейд ... 🏆`; откат одним revert.
