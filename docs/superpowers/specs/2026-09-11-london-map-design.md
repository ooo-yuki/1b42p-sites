# London — приватная карта МТТ (вместо Szeged)

Дата: 2026-09-11. Владелец: МТТ. Приватность: только он (+второй ключ DEV).

## 1. Замысел

Снос Szeged (артефакты + `tools/bake-szeged.py`), на его месте процедурный
Лондон 170×170м. Текстуры остаются: curated (4 кирпича + черепица владельца),
процедурки (штукатурка/асфальт/мембрана), плюс ~6 новых (циферблат, сланец,
лист, кора, дерево, брусчатка; image_generate, иначе процедурки).

## 2. Город

- Поле 170×170м, half = 85 + 10 = 95. Спавн — площадь у Биг-Бена.
- Канал шириной 8м вдоль оси X по z=0, вода — синяя плоскость y=-0.5.
  3 моста (deck h=1.2, ширина 6м): под мостом проход (deck даёт свободу снизу),
  по мосту ходьба. Парапеты мостов h=1 (солиды-стенки).
- Кварталы 3×3 вокруг канала и площади; улочки 4–6м между домами.
- Биг-Бен: башня 8×8м, высота 30м, циферблат-текстура на 4 сторонах верха,
  шпиль-пирамида. 2 малые башенки 5×5×18м по краям площади.
- Дома: ширина 10–16м, глубина 8–12м, высота 9–15м (3–4 этажа). Фасад на дом —
  один из 4 кирпичей (`mi % 4`, как было). Скатные крыши — декор (призмы,
  черепица), плоские — террасы с парапетом h=1.
- Интерьеры: ≥6 домов с входом (дверной проём 2м в солиде-стене), внутри пол,
  ≥2 сквозных (двери на две улицы). В комнатах пусто (мебель — позже, не скоуп).
- Вертикаль: наружные лестницы ступенями 0.5м (шаг движка держит) на ≥4
  балкона (плита deck 2×4м + перила h=1) и ≥3 крыши-террасы. Прыжок 0.96м —
  запасной путь, не основной.
- Арки: ≥5 порталов в переулках (2 столба + перекладина h≥4, проход снизу).
- Зелень: ≥12 деревьев (ствол-коробка + крона из 3 сфер-блобов, leaf-текстура),
  ≥8 лавок (сиденье + спинка + ножки, wood), ≥10 фонарей (столб + шар).
  Земля улиц — брусчатка (новая), дворы — асфальт.

## 3. Формат и движок

- Тот же `szeged-mesh-3` (positions/normals/colors/uv + индексы + atlas +
  unresolved + proc + atlas_h + core_rect + atlas_tiles): движок, preload,
  меню, сервер, gate — БЕЗ изменений. MapId `szeged` внутри сохраняется,
  display name Szeged → London (меню + MAPS).
- Солиды: стены домов (разрывы-двери!), парапеты, столбы, стволы (r-малые
  боксы), ступени (h=0.5), мосты/балконы/террасы — deck. Бюджет ≤2000.
- Ступени лестниц: боксы h=0.5 лесенкой; движок перешагивает (степ-логика).

## 4. Приватность (не трогать, регресс-тест)

Gate `shared/szeged-gate.ts`, server create/join/list/info, меню-фильтры,
devSzegedBtn, второй ключ DEV — всё как было. Только отображаемое имя.

## 5. Тесты (новые, детерминизм seed 42)

- Размер bbox ≤180, half 95; солиды ≤2000, maxbox ≤12.
- BFS-коридор 2м между 4 углами; двери: BFS сквозь ≥6 входов; крыши/балконы:
  достижимость ступенями (цепочка опор с шагом ≤0.6м вверх от земли).
- Атлас: curated+proc+новые на месте, белого <2%, тайлы ≤512, зазор ≥16.
- Старые szeged-тесты приватности — зелёные (gate не менялся).

## 6. Порядок стройки (SDD, 5 задач)

1. Генератор + улицы + дома-коробки + площадь (без интерьеров).
2. Интерьеры + лестницы + балконы + террасы (deck).
3. Канал + мосты + Биг-Бен + башенки + арки.
4. Деревья + лавки + фонари + брусчатка + 6 новых текстур.
5. Переименование в меню, тесты, сборка, живьём.

## 7. Вне скоупа
