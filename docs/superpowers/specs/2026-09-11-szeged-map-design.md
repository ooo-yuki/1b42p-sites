# Szeged — приватная карта МТТ: дизайн

**Статус:** замысел одобрен МТТ («Погнали по замыслу»), gate — строго логин `МТТ`.
**Дата:** 2026-09-11

## 1. Что в архиве (факты)

- `Szeged.zip` = один `model.dae` (14 МБ): SketchUp, ось вверх Z, единицы дюймы.
- 222k вершин, 3319 triangle-мешей, 148 материалов-плоских цветов.
- Текстурных файлов в архиве НЕТ (214 ссылок `init_from` висят в пустоту) — карта будет на цветах материалов, как МТТ и говорил («без текстур»).
- Сырые габариты огромны (~1 км) — есть выбросы/мусорные ноды; при конверсии чистим, центрируем, масштабируем к метрам игры.
- В `/tmp/szeged/model.glb` — НЕ карта, а чужая модель персонажа (старше архива, другой задачи). Игнорируем, карту печём сами из DAE.

## 2. Как устроен движок (факты)

- `mtt/.../src/game/engine.ts` (~5500 строк): все карты строятся процедурно three.js-мешами; GLTFLoader в проекте отсутствует — внешний GLB грузить нечем и не надо.
- Коллизии: AABB/circle-солиды `solids` + пространственная сетка (ячейка 6 м); земля `groundAt()` = верх ближайшего солида. Новую карту достаточно выразить мешами + списком солидов.
- Диспетчер: `buildWorld()` → `buildDuel()/buildBackrooms()/buildCustom()/buildRandom()/buildCity()`; меню: `MAPS` (4 шт); типы знают `custom/pvp/endless/invasion`.
- Сервер `server.ts`: комнаты с фиксированным `mode`, create валидирует режим вайтлистом (строка ~471), join/list отдают всем.
- Клиент знает свой логин: `GET /api/me` → `{login}`.

## 3. Подходы (выбор)

**A. Рекомендую: офлайн-запекание.** Скрипт `tools/bake-szeged.(py|ts)`: парсит DAE → чистит мусор → масштаб дюймы→метры, Z_UP→Y_UP, центр в ноль → кластеризует геометрию в AABB-солиды (стены/ящики) → печёт два артефакта: `szeged.mesh.json` (слитые позиции+нормали+цвета) и `szeged.solids.json`. Движок: `buildSzeged()` грузит артефакты, строит меши, пушит солиды. Плюсы: рантайм не парсит XML, коллизии детерминированы и тестируемы, размер под контролем. Минусы: нужен шаг запекания при правке карты.

**B. Грузить DAE в рантайме.** Отпадает: парсер Collada в бандл, 14 МБ на загрузку, коллизии из меша на лету — тяжело и нетестируемо.

**C. Приблизить карту боксами вручную (как custom).** Отпадает: 3319 мешей вручную не перебить, потеряем вид карты.

## 4. Дизайн

### 4.1 Конвейер ассетов
- `mtt.../tools/bake-szeged.py`: вход `/tmp/szeged/model.dae` (копию положим в `mtt.../tools/szeged-src/`), выход `mtt.../src/assets/szeged.mesh.json` + `szeged.solids.json`.
- Масштаб: целевой размер арены ~120×120 м (как duel/city-ядро); скрипт считает bbox, режет выбросы за 3 сигмами, масштабирует.
- Меш: слитые треугольники (position+normal+color), quantize float32→round(3). Бюджет: <2.5 МБ JSON.
- Солиды: пер-меш AABB → слияние соседних по сетке 2 м; круги не используем. Бюджет: <1500 шт (сетка 6 м держит, см. `debugCustom`/`debugMap`).
- Мелочь (<0.3 м) в солиды не идёт (мусор), но рисуется.

### 4.2 Движок
- `MapId` += `'szeged'`; `MAPS` += `{ id:'szeged', name:'🗺️ Szeged', desc:'Приватная карта МТТ' }` — пункт меню рендерится **только если** `me.login === 'МТТ'`.
- `buildSzeged()`: меши из `szeged.mesh.json` (vertexColors), солиды из `szeged.solids.json`, небо/свет как в `buildDuel` (ночь не нужна — день), спавны: 4 точки по углам без солидов (проверка `hitSolid` как в `buildWorld`).
- `buildWorld()` += ветка `szeged`; `preload()` += `szeged: []` (текстур нет — только core).
- Враги/боты: как в `duel` (без орды) — дефолт; меняется одной строкой, если МТТ захочет иначе.

### 4.3 Доступ (только МТТ)
- Клиент: пункт меню + прямые ссылки на создание Szeged-комнат скрыты, если логин ≠ `МТТ` (оборона в глубину, не единственная).
- Сервер (авторитетно):
  - `create`: `mode === 'szeged'` + `login !== 'МТТ'` → 403.
  - `join`: комната `szeged` + чужой логин → 403.
  - `list`/`rooms`: szeged-комнаты не отдаются чужим (скрытие, не только запрет входа).
- Константа `SZEGED_LOGIN = 'МТТ'` в одном месте server.ts; клиент сравнивает с тем же литералом из engine (`MAPS` gate) — дублирование осознанное (клиент и сервер не делят код), зафиксировано тестами с обеих сторон.

### 4.4 Тестирование
- `bun test`: запечённые солиды — все внутри арены, спавны вне солидов, меш-JSON валиден (треугольники бьются на 3); gate: create/join/list чужому → 403/скрыто, МТТ → ok; движок: `buildWorld` на `szeged` собирает солиды (>0) без исключений (headless, как существующие engine-тесты).
- Ревью: task-review после каждой задачи + финальный whole-branch.
