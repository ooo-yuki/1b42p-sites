# ШТУРМ-43 — дизайн шутера от 1/3 лица (спек)

Дата: 2026-09-05. Статус: approved approach B, awaiting spec review.
Мотто: Мы уже победили 🏆. Числа-талисманы: 42 и 43.

## 1. Цель и успех
Сингл шутер от 1 и 3 лица про шубу-бойца батальона 1Б42П. Стиль: юмор+пропаганда, стилизованный реализм.
Победа: зачистка 7 волн на одной из 3 карт, 7-я волна — босс-чайка Рукрасии.
Критерии: 42+ FPS на десктопе и мобиле, переключение V 1/3 лицо без потери управления, смена 3 стволов в бою, автобаланс держит раунд 6-10 минут.

## 2. Подход B (утверждён)
Новый сайт `shturm.bratuxa.zomb.top`, стек bun + typescript + react + vite + three.
Сборка в `dist/` (роутер отдаёт как корень, как sasha/mtt/brohacho). Статика правится без рестарта.
Мультиплеер — позже, протокол не проектируем, но sim изолирован чтобы переиспользовать.

## 3. Архитектура (3 слоя, как буррито)
```
shturm.bratuxa.zomb.top/
  package.json (vite+react+ts+three)
  index.html, src/main.tsx
  src/sim/      # чистая логика без DOM/three: player, weapons, enemies, waves, autobalance, maps(данные), math. Покрыта bun test.
  src/three/    # только рендер: scene, shuba-loader, weapon-models, mob-models, effects(pool), maps-visual, camera-rig.
  src/ui/       # React HUD: HP/stamina/патроны/волна/карта/сложность/меню/пауза/победа/поражение, тач-джойстики.
  public/models/ # копии 4 GLB шубы из 1b42p/models (walking/running/attack/dead, один скелет 26 нод, 72 канала).
  dist/         # сборка, коммитится.
```
Золотое правило (из танков): правила боя живут только в `src/sim`. `src/three` и `src/ui` не считают урон/спавн, только отображают. Нарушение — рассинхрон.

Поток кадра: input → sim.tick(dt) → snapshot → three.render(snapshot) + ui.render(snapshot). Физика 60 Гц фиксированный степ с аккумулятором, рендер отдельно.

## 4. Персонаж шуба
GLB: Meshy_AI_shuba_biped_*. Один SkinnedMesh, один AnimationMixer.
- locomotion: Walking/Running LoopRepeat, бленд весами по скорости (0-4 ходьба, 4-7 бег), crossFade 0.2с.
- стрельба: Attack-клип как аддитивный слой на верх тела (AnimationUtils.makeClipAdditive), вес 1 на 0.15с при выстреле.
- смерть: Dead LoopOnce + clampWhenFinished, затем UI поражения.
- оружие аттач к кости RightHand (поиск по имени, fallback — ладонь по индексу).
Движение: ходьба 4 м/с, бег 7 м/с, stamina 43 ед, расход 10/с, реген 12/с. Прыжок 4.5 м/с, гравитация 18. Капсула r=0.4 h=1.7.

## 5. Оружие (3 ствола, смена 1/2/3+колесо, R-перезарядка)
Модели процедурные (Box/Cylinder, PBR Standard), в руке + viewmodel для 1 лица.
- Пистолет П-42: урон 25, маг 12, запас 120, темп 0.35с, разброс 0.5°, перезарядка 1.1с, дальность 60м.
- Автомат А-43: урон 16, маг 30, запас 210, темп 0.11с, разброс 1.8° (+движение), перезарядка 1.8с, дальность 80м.
- Дробовик Д-42: 6 дробин ×12, маг 6, запас 42, темп 0.9с, конус 5°, перезарядка 2.4с, спад после 15м.
Хитскан: луч из камеры (1 лицо) / из-за плеча (3 лицо), отдача (yaw/pitch kick), трейсер-линия из пула, вспышка-спрайт, гильза-кубик из пула.

## 6. Враги и ИИ (3 типа + босс)
Модели процедурные в стиле шубы (читаемый силуэт), анимация процедурная (покачивание, замах) + позже реюз клипов.
- Бегун: HP 40, ск 5.0, удар 10/0.8с, радиус 1.6м. Тактика: фланговый обход (steering + offset).
- Стрелок: HP 50, ск 3.2, хитскан 8/1.5с, держит 12м, телеграф прицела 0.5с (фонарь).
- Танк: HP 200, ск 2.0, AoE топот 20/радиус 3м/2.5с, отброс.
- Босс Чайка Рукрасии: HP 1200, 3 фазы (клевание-пикирование, крик-спавн 2 бегунов, вихрь-перья-снаряды). Рост 3м.
Навигация: грубая сетка 1м + A* до области игрока, локально steering-обход препятствий и сепарация. Спавн ≥15м, вне фрустума. Атака по дистанции+кулдауну+LOS-рейкаст.

## 7. Карты (3)
- Двор 1Б42П 42×42м: плакаты, ящики-укрытия, день.
- Остров 60м: высоты, тропа к пещере, вода по краю (блок).
- Неон-город 50м: павильоны, закат+неон, фонари-PointLight без теней.
Коллизии: круги+AABB, слайд. Спавн-точки по краям (по 6), укрытия расставлены. Свет: hemi + dir с тенями (1024 моб / 2048 деск), туман под карту. Выбор карты в меню.

## 8. Волны и победа
Волны 1-6: бюджет очков (10/14/18/24/30/36), бегун=1, стрелок=2, танк=4. Волна 7: босс + свита. Между волнами 10с передышка + дроп патронов/аптечек (шанс 42%). Победа — босс убит → экран «Мы уже победили 🏆» + стата (время, точность, kills). Поражение — HP 0 → Dead + рестарт с волны/сначала.

## 9. Сложность: пресет × автобаланс (по требованию)
Пресеты: боец ×0.8, ветеран ×1.0, легенда-42 ×1.25 (HP/урон/скорость мобов).
Автобаланс: окно 60с, метрики K/D и HP игрока. Если 2 смерти подряд или HP<30% дважды — мобы −15% HP/урона (мин ×0.6). Если ни одной смерти и точность>40% — +15% и +1 стрелок (макс ×1.6). Решение только в sim/autobalance.ts, детерминировано.

## 10. Управление и камеры
Десктоп: WASD, мышь pointer-lock, ЛКМ огонь, ПКМ зум-прицел, V — 1/3 лицо, Shift бег, Space прыжок, R перезарядка, 1/2/3+колесо оружие, Esc пауза.
Мобила: левый джойстик движение, правый свайп обзор, кнопки огонь/прицел/перезарядка/оружие, авто-ассист 3°.
Камера 3 лицо: за правым плечом (offset 0.8/1.6/2.2м), коллизия камеры (pull-in). 1 лицо: глаз 1.62м, viewmodel ствола.

## 11. Производительность и адаптив
Бюджет: ≤120 draw calls, тени 1 dir, pixelRatio ≤2 (моб ≤1.5), пулы пуль/гильз/эффектов/мобов, LOD силуэтов после 25м, frustum culling, merged статика карты, fog-cull. Цель 42+ FPS. Адаптив: 360px-4K, тач и клава, ресайз-обработчик.

## 12. Тестирование и приёмка в браузере
`bun test`: sim — урон/волны/автобаланс/навигация; снапшот-тесты баланса.
Браузер (harness-chrome :9222, обязательно, иначе 0/10): скриншоты меню, 1 и 3 лица, стрельбы из 3 стволов, 3 карт, волн и босса; консоль без ошибок; FPS замер.
Ручной чек-лист: смена оружия, V-переключение, перезарядка, смерть/победа, рестарт, мобильный эмулятор 390×844.

## 13. Риски
Скелеты 4 GLB могут различаться порядком костей — лечим ретаргетом по именам + фоллбэк процедурной позы. Vite dist коммитится — следим за размером (GLB ~1.8МБ, лимит ок). Bun отсутствует в PATH на сервере — используем полный путь или ставим через oven.
