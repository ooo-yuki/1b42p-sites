# MIQQIL TANKS — правила для агентов

Танки в стиле War Thunder + battle royale, батальон 1Б42П. Мы уже победили 🏆

## Что это и как работает

Один общий бой на всех: сервер держит авторитарный мир и тикает его сам,
браузер — только ввод и рендер. Все, кто зашёл, оказываются в одном раунде;
ботов достаточно, чтобы добить состав до 8 бойцов.

```
game-logic.js  ТТХ техники, урон, зона, Elo-рейтинг, ники ботов. Без DOM, без сети.
sim.js         Авторитарная симуляция: арена по сиду, движение/коллизии, хитскан,
               боты, раунд-машина (waiting→live→results→intermission→live…).
               Импортируется и сервером, и клиентом — ЕДИНЫЙ источник правил боя.
models.js      three.js-визуал: сцена/свет/небо, модели техники, эффекты. Никакой
               игровой логики — только рендер того, что скажет sim.js.
net.js         WebSocket-клиент: реконнект с бэкоффом, интерполяция снапшотов.
index.html     UI/HUD/камера/ввод. Держит собственный локальный sim.js-мир для
               офлайн-фоллбека (сервер недоступен) и для предсказания своего танка.
server.ts      Bun: REST (/api/register, /login, /match, /leaderboard) + один
               глобальный WS-мир (/api/ws) на 30 Гц, снапшоты 15 Гц.
router.py      (в /root/sites, общий на все поддомены) — TLS-терминация, проксирует
               /api/* на 127.0.0.1:8091, включая сырой TCP-туннель для /api/ws.
```

**Золотое правило:** правила боя (движение, урон, зона, раунды, боты) живут только
в `sim.js`. Если что-то меняется в логике — меняй там, а не дублируй в `index.html`
или `server.ts`. Клиент и сервер обязаны крутить один и тот же код симуляции.

## Команды

```bash
cd /root/sites/miqqil.bratuxa.zomb.top
bun test                 # tests/*.test.ts — держи зелёными перед коммитом
bun run server.ts        # запуск API в форграунде для отладки (нужен DATABASE_URL)
```

Продакшен крутится через systemd, не через `bun run` вручную:

```bash
systemctl restart miqqil-api   # подхватить новый server.ts/sim.js/game-logic.js
systemctl restart chaev-site   # подхватить новый router.py (общий для всех сайтов!)
journalctl -u miqqil-api -n 50 --no-pager
```

`index.html`/`models.js`/`net.js` отдаются статикой — правки видны сразу после
сохранения, рестарт не нужен. `chaev-site` — общий роутер на ВСЕ поддомены
(chaev/denis/hub/setden/svyatoslav), рестартуй его осторожно и только когда
правда менял `router.py`.

Живой адрес: https://miqqil.bratuxa.zomb.top

## Протокол WS (`/api/ws`)

Клиент → сервер: `{t:'join', token?, nick, veh}` · `{t:'input', dx, dz, aimYaw, fire}` · `{t:'ping', ts}`
Сервер → клиент: `{t:'welcome', id, seed, arenaSize}` · `{t:'state', time, units[], zone, round, events[], online}` · `{t:'rating', rating, delta}` · `{t:'pong', ts}`

`dx`/`dz` — уже мировой вектор движения (клиент считает его из своего `camYaw`,
сервер не знает про камеру). `aimYaw` — куда целится игрок (рейкаст с центра
экрана), сервер доворачивает башню сам с ограничением `turretTurn`. HP/позиции/
исход раунда всегда считает сервер — клиенту верить нельзя.

Арена по сети НЕ едет: клиент получает только `seed`+`arenaSize` в `welcome` и
строит те же препятствия/декор через `Sim.makeArena(seed, size)` — она
детерминирована (`mulberry32` в `game-logic.js`).

## Известные грабли

- **`self.rfile.peek()` в `router.py` — НЕ трогать.** У `BaseHTTPRequestHandler`
  этот метод блокируется, если буфер пуст (реально дёргает `recv()`). В
  WS-прокси это вешало рукопожатие намертво, потому что клиент по протоколу
  ждёт 101-ответ и ничего не шлёт первым. Если снова понадобится «долить
  оставшиеся байты из rfile» — не надо, WS-клиенты не шлют тело до апгрейда.
- Не гейти стрельбу на клиенте таймером — `reload` считает `sim.js`, клиент
  просто шлёт `fire:true` пока зажата кнопка/пробел.
- Не пиши новый бой напрямую в `index.html` (спавн ботов, урон и т.п.) — это
  уже один раз привело к рассинхрону клиента и сервера, когда логика жила в
  двух местах. Только `sim.js`.
- Рейтинг в Neon пишется только тем, кто отыграл раунд с начала (`fullRound`).
  Зашедшим посреди раунда — честный бой без штрафа, но без рейтинга за этот
  раунд.

## Стиль

- Комментарии и UI-тексты — по-русски, дух батальона 1Б42П: коротко, с
  самоиронией, эмодзи к месту. Мотто `Мы уже победили 🏆` — можно вставлять,
  но не в каждый файл.
- Ванильный ES-модули + `three.js` через importmap (CDN jsdelivr), без
  сборщика. Не тащи бандлер/фреймворк ради одной фичи.
- Коммиты в стиле репозитория: одна строка, префикс `miqqil:`, эмодзи в конце.
  Пример: `miqqil: mouse-look камера + общий мультиплеер на WS 🏆`
