# DESIGN.md — Skitons Cafe

## Direction contract
THESIS: кафе-коробочка из пастельного пластилина: снаружи — домик с верандой и зонтиками, внутри — столики с паром над чашками, на кухне — повар у плиты. Категория-тайкуны обычно тёмные/цифровые; мы отказываемся в пользу тёплого света и кукольных людей.
OWN-WORLD: пастель (крем #f7ece1, персик #ffd9c0, мята #cdeac0, небо #bfe3ff, какао #8a6a5a), округлые low-poly формы, мягкие тени PCFSoft, туман cream. UI — кремовые пилюли, скругление 16px, один акцент какао.
STORY: игрок видит кафе целиком, тыкает апгрейды, кафе хорошеет прямо на глазах; гости приходят, едят, уходят довольными.
FIRST VIEWPORT: 3D-сцена 100% экрана; сверху HUD-пилюля (монеты, гости, рейтинг); снизу таб-бар 5 веток + камеры (Снаружи/Зал/Кухня); панель апгрейдов — нижний шит с карточками (название+цена+уровень-точками).
FORM: code-led Operate. Подпись: плавный перелёт камеры + пар над чашками.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Токены
- Фон: #f7ece1, туман #f7ece1 30..90
- Свет: hemi (небо #fff4e0 / земля #d9b8a3, 0.75) + dir тёплый (1.1, тени 1024) + ambient 0.25. Без пересветов: ACESFilmic, exposure 1.0.
- Шрифт: system rounded stack. Трекинг −0.02em. Заголовки ≤2rem.
- Радиусы 12–16px, пилюли для контролов. Иконки — инлайн SVG, эмодзи запрещены.

## Люди
Кукольные: голова-сфера, тело-капсула, глаза — две тёмные сферы (эмоция читается), роль — цветом фартука/колпака: официант — персик, повар — белый колпак, уборщик — мята, гость — случайная пастель.
