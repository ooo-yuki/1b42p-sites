# Surface: lobby — комнаты, рега, профиль

Рега: логин+пароль (`mtt_users`, хеш `Bun.password`), гость, токен `mtt_token`.
Комнаты: код 6 символов, arena/duel; вход = заявка, пускает создатель (approve),
кик, 🚀 СТАРТ — гости стартуют авто-входом. Пульс 0.5с в бою / 1.5с в меню.

Direction-контракт: создатель — один (`owner`, переход старшему при уходе);
состав чужим не светить (`info` отдаёт sid только своим); дуэль строго 1×1;
профиль скрыт до клика; админ-онлайн только `ADMIN_LOGIN`, остальным 403.
